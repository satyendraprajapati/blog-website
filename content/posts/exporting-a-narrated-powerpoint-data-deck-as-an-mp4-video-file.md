---

Recording a narrated walkthrough of a data deck solves the "can't make the live meeting" problem, but a `.pptx` file that needs PowerPoint installed and the right fonts loaded isn't the easiest thing to forward. Exporting it as an actual video file closes that gap — anyone can open an MP4 in a browser or phone player, no PowerPoint required.

**1. Record the narration first; the export step doesn't add it for you.** Go to **Slide Show > Record Slide Show** and talk through each slide the way you would live, with the laser pointer, ink annotations, and timing captured automatically. Export to Video only packages what's already recorded — if a slide has no narration or timing, it'll play on screen for whatever default duration you set, which usually looks wrong.

**2. Export from File > Export > Create a Video.** This converts every slide, its recorded timing, narration, and any animations into a single video file rather than a presentation that needs an app to open.

**3. Pick a resolution that matches where people will actually watch it.** PowerPoint offers presets from "Standard" up to "Ultra HD (4K)." For a data deck going to a laptop or a Teams/Slack share, **Full HD (1080p)** is the sweet spot — sharp enough to read a chart's axis labels, without producing a file so large it's awkward to email or upload. Save 4K for a deck that will be projected on a large screen or has especially dense tables that need the extra pixels to stay legible.

**4. Set seconds-per-slide only for slides without recorded narration.** If some slides in the deck were never recorded, PowerPoint uses the "Seconds spent on each slide" setting as a fallback — the default is 5 seconds, which is rarely enough time to read a chart. Bump it to 10-15 seconds for any data-heavy slide that didn't get a voiceover, or go back and record narration for it instead so the pacing isn't left to a guess.

**5. Budget real time for the export itself.** Unlike saving a `.pptx`, creating a video is a rendering process — PowerPoint has to play through the whole deck frame by frame. A 20-minute narrated deck with charts and transitions can take several minutes to export, and the file stays open (though usable) in the background while it does. Don't close PowerPoint or start the export right before you need to send the file.

**6. Check the file size before sending it the way you'd send a `.pptx`.** A 15-minute 1080p export easily lands in the 100-300 MB range depending on how much motion and how many high-resolution screenshots are in the deck — often too large for an email attachment. Upload it to the same place you'd host a recorded meeting (OneDrive, SharePoint, Teams) and share the link instead of the file itself.

**7. Keep the original `.pptx` too — the video isn't editable.** Once exported, the MP4 is a flattened recording; fixing a typo or updating one number means re-recording the affected slides and exporting again, not editing the video directly. Treat the video as the distribution copy and the `.pptx` as the source you keep working from.

The result is a deliverable that survives outside the meeting it was built for — a stakeholder who missed the readout gets the same narrated walkthrough everyone else saw, on whatever device they happen to be using.
