---

Every data deck accumulates slides that don't belong in the main narrative but are too useful to delete outright — the methodology detail, the regional breakdown someone might ask about, the chart that got cut for time. Deleting them means rebuilding from scratch if a question comes up; leaving them in the main flow pads a tight story with detail nobody asked for. **Hide Slide** is the feature built for exactly this middle ground, and it's easy to miss because it lives in a right-click menu rather than the ribbon.

**1. Right-click a slide thumbnail and choose Hide Slide.** The thumbnail dims and gets a diagonal strikethrough over its number — a visual flag that it's still in the file but won't appear during a normal Slide Show. Nothing about the slide's content changes; only its playback behavior does.

**2. A hidden slide is skipped automatically when presenting front-to-back.** Pressing the spacebar or clicking through the deck in Slide Show mode jumps straight past any hidden slide to the next visible one — the audience never sees it and never sees a gap where it was.

**3. Jump to it anyway during Q&A with right-click → See All Slides, or by typing its number and Enter.** During a live presentation, right-clicking anywhere and choosing "See All Slides" (or "Show Presenter View" grid) shows every slide, hidden ones included, marked with the same dimmed strikethrough — click one and it displays immediately, out of sequence, then returns to wherever you left off. Typing a slide's number and pressing Enter jumps to it the same way, hidden or not, which is faster once you know the deck well enough to remember the numbers.

**4. Build a dedicated appendix section entirely out of hidden slides.** Combining this with Sections — one section literally named "Backup," containing every hidden slide — keeps them physically organized at the end of the file instead of scattered wherever they were originally built, so they're easy to find and update later without hunting through the whole deck.

**5. Use it for audience-specific detail instead of duplicating a whole deck.** A single source deck with the executive summary always visible and department-specific detail slides hidden lets one presenter reuse the same file for different audiences, unhiding only the section relevant to whoever's in the room that day — no separate copies to keep in sync when a number changes upstream.

**6. Don't confuse it with Custom Shows.** Hide Slide is a single on/off flag per slide within one linear deck; **Custom Shows** (under Slide Show → Custom Slide Show) defines multiple named, reorderable subsets of slides for genuinely different presentations built from the same file. Reach for Hide Slide when it's "keep this on standby for the same audience"; reach for Custom Shows when it's "build two different decks from shared slides."

**7. Check for hidden slides before exporting to PDF or handing off the file.** Exporting to PDF or "Create Handouts" includes hidden slides by default unless you explicitly tell it not to — a slide hidden from the live audience can still leak into a leave-behind document if you don't catch it in the export dialog first.

The feature costs nothing to use and nothing to maintain — a hidden slide updates along with the rest of the deck's theme and data links, sits ready the moment a question calls for it, and never once shows up to an audience that didn't ask.
