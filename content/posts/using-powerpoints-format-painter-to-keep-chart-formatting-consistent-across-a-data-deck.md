---

Rebuilding a slide master is the right fix when you're setting up a template from scratch, but most decks don't start that clean — you end up with one chart formatted exactly the way you want, and nine more built at different times with slightly different colors, fonts, or line weights. Reformatting each one by hand is slow and easy to get inconsistent. Format Painter copies the finished formatting from one chart or shape and applies it to another in two clicks, no template rebuild required.

**1. Select the chart that already looks right**, click it once to select the whole object rather than an individual element inside it, then click Format Painter on the Home tab (the paintbrush icon). Your cursor changes to a small brush, signaling PowerPoint is ready to copy that chart's formatting.

**2. Click the next chart to apply it.** Everything about the source chart's visual formatting — series colors, font, axis line weight, data label style, legend position — transfers onto the target chart, while the actual data each chart plots stays untouched. This is the detail that makes it useful for a data deck specifically: you're copying the look, never the numbers underneath it.

**3. Double-click Format Painter instead of single-clicking** when you have more than one chart to fix. A single click copies formatting once and then turns itself off after the first paste; double-clicking keeps it active so you can click through every remaining chart in the deck in one pass, then press Esc to turn it off when you're done.

**4. Use it across chart types, not just identical ones.** A bar chart's color scheme and font formatting can be painted onto a line chart or a table just as easily — PowerPoint applies whatever formatting properties are shared between the two object types and skips the ones that don't apply, so a color palette can travel from a bar chart to a KPI card without you resetting each fill color by hand.

**5. Reach for it mid-review, not just at build time.** The moment this earns its keep is a last-minute request in a review cycle — a stakeholder wants the accent color changed, or someone copy-pasted a chart from an old deck with the wrong theme. Fixing the one chart correctly and painting that formatting onto the rest takes seconds, versus reopening every chart's Format pane individually.

**6. Know when to stop reaching for it.** Format Painter is a one-off fix, not a system — if you're painting the same formatting onto new charts every week, that's a sign the underlying Slide Master or chart template should carry that formatting by default instead. Treat it as the fast patch for an existing deck, and fix the template once you notice you're reaching for the paintbrush on every new report.

It's a small, easy-to-forget tool next to bigger features like Slide Master or Designer, but for the specific job of making a deck's charts match without reformatting each one from scratch, it's usually the fastest thing in the ribbon.
